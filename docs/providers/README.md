# Payment providers

Written confirmations of each provider's contract, one folder per provider (`mtn-momo/` first). An adapter is built only from what is recorded here and confirmed in writing, never from generic documentation (05 §3).

Each provider's folder should hold:

- The confirmed integration notes: API version, callback authentication, status query, rate limits, refunds, statements, sandbox behaviour.
- The capability matrix and stop rules (00 §4).
- The adapter certification report, once F1–F15 have been run (05 §3).

Nothing here is confirmed yet.
