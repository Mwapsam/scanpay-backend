# Architecture decision records

One file per ADR, named `ADR-NNN-short-title.md`, written from [template.md](template.md). The current list and statuses are in 05 §7. Add an ADR file only when a decision is actually made or formally proposed with an owner; don't record a guess as a decision.

Status words: Proposed, Open, Accepted, Decided, Superseded (see CLAUDE.md for their meanings).
